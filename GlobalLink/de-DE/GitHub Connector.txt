GlobalLink Connect GitHub Connector – Überblick

Änderung vorgenommen am 15. Okt. 2026

Der GlobalLink Connect GitHub Connector ist eine webbasierte Anwendung, die GitHub mit GlobalLink Connect integriert und es den Nutzern ermöglicht, Übersetzungsanfragen für Inhalte zu erstellen, die in einem GitHub-Repository gespeichert sind.

Wenn eine Übersetzungsanfrage initiiert wird, stellt der Connector eine Verbindung zum GitHub-Repository her und klonen sowohl den Quell- als auch den Zielzweig auf den GlobalLink Connect-Server. Der Quellzweig wird für den Export verwendet, während der Zielzweig für die Bereitstellung übersetzter Inhalte genutzt wird. Jeder Zweig wird in einem separaten Arbeitsverzeichnis verwaltet.

Arbeitsablauf

1. Erstellen und Aktualisieren von Dateien
   Nutzer erstellen oder aktualisieren Quellinhalte im GitHub-Repository.

2. Abrufen von Repository-Inhalten
   Der GitHub Connector führt einen Git-Pull-Vorgang aus, um die neuesten Dateien aus dem Repository abzurufen und speichert sie im Arbeitsordner von GlobalLink Connect.

3. Branch-Management
   Dateien werden gemäß ihrer entsprechenden Zweigstruktur organisiert. Wenn ein erforderlicher Zweig noch nicht auf dem Server vorhanden ist, wird er automatisch geklont.

4. Dateiauswahl für die Übersetzung
   Basierend auf konfigurierten Abfrage- und Filterkriterien werden geeignete Dateien identifiziert und zur Übersetzung in die erforderlichen Zielsprachen an GlobalLink Connect übermittelt.

5. Übersetzung und Überprüfung
   Inhalt wird im GlobalLink TMS TMS übersetzt und überprüft. Nach Abschluss werden die übersetzten Dateien mit Beibehaltung der ursprünglichen Verzweigungsstruktur wieder in den Arbeitsordner zurückgegeben.

6. Übersetzten Inhalt einchecken
   Gelieferte Übersetzungen werden zur Zielzweig hinzugefügt, lokal eingecheckt und auf Synchronisation vorbereitet.

7. Änderungen an GitHub pushen
   Der Konnektor pusht die eingecheckten Übersetzungen zurück ins entfernte GitHub-Repository. Je nach konfiguriertem Workflow kann auch automatisch ein Pull-Request zur Überprüfung und Genehmigung erstellt werden.

8. Ergebnisse anzeigen
   Aktualisierter übersetzter Inhalt wird im GitHub-Repository verfügbar, wo Teams Änderungen überprüfen, Pull-Anfragen zusammenführen und den Entwicklungslebenszyklus fortsetzen können.

Wichtige Vorteile

• Automatisierte Synchronisierung zwischen GitHub und GlobalLink Connect
• Unterstützung für die Übersetzung aller Repository-basierten Inhaltstypen
• Erhaltung der Zweigstrukturen während des gesamten Lokalisierungsprozesses
• Automatisierte Commits und Repository-Aktualisierungen
• Optionale Erstellung von Pull-Anfragen zur Unterstützung von Entwicklungsworkflows
• Nahtlose Integration von Übersetzungsaktivitäten in bestehende GitHub-Prozesse
